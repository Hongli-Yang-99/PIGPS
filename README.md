# 聚酰亚胺设计智能体 v1.0.0 — Windows 在线安装版

### 主要功能
- 通过自然语言进行聚酰亚胺生成、性能预测和计算任务管理。
- 支持准确、标准、新颖三种生成模式，以及参考结构引导生成。
- 预测介电常数、玻璃化转变温度、热膨胀系数、模量、断裂应力和韧性。
- 支持批量预测、结构可视化、模型解释和结果导出。
- 可连接兼容的 Slurm 集群，提交并管理 VASP/LAMMPS 计算。
- 支持中文和英文界面。

### 安装方法
下载附件中的完整 ZIP，解压后运行在线安装器。

首次安装需要联网下载模型与运行依赖；安装完成后，本地生成、预测和对话可离线运行。远程计算需要连接集群。

### 最低推荐配置
- 操作系统：Windows 11
- 显卡：NVIDIA RTX 3050，8 GB 显存
- 处理器：Intel Core i7-11700
- 内存：16 GB
- 可用磁盘空间：35 GB

支持 CPU 模式，但生成速度会明显降低。

# Polyimide Design Agent v1.0.0 — Windows Online Installer

### Features
- Polyimide generation, property prediction, and computational task management through natural-language interaction.
- Three generation modes: Accurate, Standard, and Novel, with support for reference-guided generation.
- Prediction of dielectric constant, glass transition temperature, coefficient of thermal expansion, modulus, fracture stress, and toughness.
- Batch prediction, molecular structure visualization, model interpretation, and result export.
- Connection to compatible Slurm clusters for submitting and managing VASP/LAMMPS calculations.
- Chinese and English interfaces.

### Installation
Download the complete ZIP attached to this release, extract it, and run the online installer.

An internet connection is required during installation to download the models and runtime dependencies. After installation, local generation, prediction, and conversations can run offline. Remote calculations require a connection to the cluster.

### Minimum Recommended Configuration
- Operating system: Windows 11
- GPU: NVIDIA RTX 3050 with 8 GB VRAM
- Processor: Intel Core i7-11700
- RAM: 16 GB
- Available disk space: 35 GB

CPU mode is supported, but generation will be substantially slower.
